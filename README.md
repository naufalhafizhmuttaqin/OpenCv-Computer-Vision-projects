# OpenCv-Computer-Vision-projects

This repository contains a collection of real-time computer vision projects built using **Python**, **OpenCV**, and **MediaPipe**. Each project focuses on different human interaction detection tasks and is suitable for learning, research, and portfolio purposes.

## Projects Included

### 1️⃣ Eye Blink Detection & Drowsiness Counter
Detects eye blinks in real time and counts them to estimate user alertness and drowsiness level.
- Technologies: OpenCV, MediaPipe, Python
- Features:
  - Real-time webcam detection
  - Blink counting
  - Drowsiness alert system

---

### 2️⃣ Facial Emotion Detection
Recognizes facial expressions and classifies emotions such as happy, sad, angry, and surprised.
- Technologies: OpenCV, Machine Learning / Deep Learning
- Features:
  - Face detection
  - Emotion classification
  - Real-time emotion visualization

---

### 3️⃣ Finger Counter
Counts the number of fingers shown to the camera using hand landmark detection.
- Technologies: OpenCV, MediaPipe
- Features:
  - Hand landmark tracking
  - Finger counting logic
  - Real-time display

---

### 4️⃣ Hand Gesture Detection
Detects and classifies various hand gestures for human-computer interaction.
- Technologies: OpenCV, MediaPipe
- Features:
  - Multi-hand detection
  - Gesture recognition
  - Real-time interaction

---
